QUICK START — Deploy escolhe-ai na Railway
==========================================

1. Conta Railway + repo GitHub conectado
2. Adicionar PostgreSQL (DATABASE_URL automático)
3. Variáveis: RAILS_MASTER_KEY, SECRET_KEY_BASE, SendGrid, Google OAuth, API keys
4. Domínio customizado + DNS
5. Push em master (ou Deploy no dashboard)

Healthcheck: /up
Start: migrate + rails server na $PORT

Detalhes: DEPLOY_RAPIDO.md e DEPLOYMENT.md

Local (dev):
  bundle install
  rails db:setup
  rails server

Docker local (opcional):
  docker compose up --build

## Implementation Notes

### Why Coolify + Hetzner?
- **Coolify** = Dashboard para gerenciar deployments, sem vendor lock-in
- **Hetzner** = VPS barato (~€5-20/mês) com boa performance
- **Self-hosted** = Controle total, sem limites de Railway ou Heroku
- **Docker-native** = Leverages Dockerfile já existente

### Architecture
```
┌─ Hetzner VPS (Ubuntu 24.04)
│  └─ Coolify
│     ├─ Rails app container
│     ├─ PostgreSQL container (ou external DB)
│     └─ Nginx reverse proxy (automático)
├─ GitHub (source code + webhooks)
└─ Let's Encrypt (SSL certificates)
```

### Deployment Flow
1. Push para `main` branch
2. GitHub webhook → Coolify
3. Coolify clona repo, build Docker image
4. Stop container antigo, start novo
5. DB migrations automáticas (via CMD no Dockerfile)
6. Healthcheck valida antes de aceitar tráfego

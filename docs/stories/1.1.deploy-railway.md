# Story — Deploy em Railway

## Goal

Rodar EscolheAi em produção na Railway com Docker + PostgreSQL gerenciado.

## Acceptance

- [ ] Projeto Railway com repo GitHub conectado
- [ ] `railway.toml` + `Dockerfile` buildando com sucesso
- [ ] PostgreSQL linkado (`DATABASE_URL`)
- [ ] Variáveis de ambiente definidas
- [ ] Healthcheck `/up` passando
- [ ] Domínio `escolheai.net` / `www` com SSL
- [ ] Google OAuth callbacks atualizados
- [ ] Documentação atualizada

## Tasks

1. Criar projeto Railway e conectar `Jou82/escolhe-ai`
2. Provisionar Postgres e linkar ao serviço web
3. Configurar Variables (secrets)
4. Configurar custom domains + DNS
5. Validar deploy (login, recomendações, email)

## Architecture

```
GitHub → Railway Docker build → Web (Puma) → Railway Postgres
                ↑
         railway.toml / Dockerfile
```

## Notes

- Rails: `assume_ssl` porque o proxy Railway termina TLS
- Start command em `railway.toml`
